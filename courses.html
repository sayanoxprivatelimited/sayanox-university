Python Basics

Python is a general-purpose language used for automation, web applications, data analysis and machine learning. Its readable syntax makes it a welcoming first language, while its ecosystem supports serious production work.

Background: Created by Guido van Rossum; first released in 1991.

1. Meet Python

Python is a readable, widely used programming language. Use print() to display text. To practice, install Python and run it in a terminal, or use a trusted online Python environment.

print("Hello, world!")
print("I am learning Python")

Practice: Print a greeting using your own name.

Learn step by step

  1. Read the two print calls and predict the two lines of output.
  2. Run the example in the practice studio and compare its output with your prediction.
  3. Replace the second message with a greeting containing your name, then run it again.

Tip: Keep the quotation marks paired. Text inside the quotes is a string, not a command.

2. Variables and data

Variables store information. A string contains text, while an integer is a whole number. Python infers the type from the value. Use an f-string to insert variables into text.

name = "Mita"
age = 18
print(f"Hello {name}, age {age}")

Practice: Store your favorite subject in a variable and print it.

Learn step by step

  1. Identify the string assigned to name and the integer assigned to age.
  2. Predict the output of the f-string before running it.
  3. Change both values and run the program again.

Tip: Use quotes for text. In an f-string, put the variable name inside braces and place f before the opening quote.

3. Conditions and loops

Use if to run code conditionally and a for loop to repeat an action. Indentation—the whitespace at the start of a line—is important in Python.

for number in range(1, 4):
    if number > 1:
        print(number)

Practice: Print the numbers from 1 to 5 and identify the even numbers.

Learn step by step

  1. List the values produced by range(1, 4): 1, 2 and 3.
  2. For each value, decide whether number > 1 is true.
  3. Run the program and explain why it prints 2 and 3, not 1.

Tip: The end value in range(1, 4) is excluded. Keep the indented lines aligned within their blocks.

4. Functions and return values

Functions group reusable behavior. Parameters receive input, and return sends a result back to the caller. Give functions names that describe what they do and test them with different inputs.

def square(number):
    return number * number

print(square(5))

Practice: Write a function that converts minutes to seconds. Test it with zero and a positive value.

Learn step by step

  1. Find the parameter number in the function definition.
  2. Trace square(5): substitute 5 for number and calculate 5 * 5.
  3. Change the argument, rerun the example and compare the returned value.

Tip: return sends a value back; print displays a value. A function can return a result without printing it.

5. Handling errors

Programs can fail when input is invalid. Use try and except to handle expected exceptions without hiding unrelated problems. ValueError occurs when text cannot be converted to an integer.

try:
    number = int("42")
    print(number * 2)
except ValueError:
    print("Please enter a whole number")

Practice: Change the input to non-numeric text and observe the result.

Learn step by step

  1. Run the example with "42" and observe the result 84.
  2. Change "42" to "hello" and rerun it.
  3. Compare the two outputs and identify which block handled the invalid input.

Tip: Catch errors you expect. Avoid hiding unrelated errors, which can make bugs harder to find.

Getting Started with Rust

Rust is a systems language designed to combine performance with strong memory-safety guarantees. Its ownership model helps catch many errors before a program runs.

Background: Started by Graydon Hoare at Mozilla; the first stable release arrived in 2015.

1. Meet Rust

Rust is a systems programming language that emphasizes performance and memory safety. After installing Rust, create a project with cargo new hello and run it with cargo run.

fn main() {
    println!("Hello, Rust!");
}

Practice: Change the program to display a message with your name.

2. Variables and mutability

In Rust, let creates a variable. Variables are immutable by default; use mut when a value needs to change. Rust can often infer the type.

fn main() {
    let mut score = 1;
    score += 1;
    println!("Score: {}", score);
}

Practice: Create a mutable counter and increase its value.

3. Understanding ownership

Each value in Rust has an owner. When its owner leaves scope, the value is cleaned up. Borrowing lets you use a reference without taking ownership, helping keep memory safe.

fn main() {
    let name = String::from("Sayanox");
    let borrowed = &name;
    println!("{}", borrowed);
    println!("{}", name);
}

Practice: Create a String and print it through a reference.

4. Functions and control flow

Functions use fn and may return a typed value. An if expression can select a value; both branches must have compatible types.

fn double(value: i32) -> i32 {
    value * 2
}

fn main() {
    println!("{}", double(4));
}

Practice: Write a function that returns the larger of two integers.

5. Recoverable errors

Rust represents recoverable errors with Result<T, E>. Match forces you to consider success and failure explicitly, rather than silently ignoring an error.

fn main() {
    let parsed = "42".parse::<i32>();
    match parsed {
        Ok(n) => println!("{}", n),
        Err(e) => println!("Invalid number: {}", e),
    }
}

Practice: Try parsing a word instead of a number and inspect the error.

C Programming

C is a foundational compiled language used in operating systems, embedded devices and performance-sensitive software. It offers a close view of how programs use memory.

Background: Developed by Dennis Ritchie at Bell Labs in the early 1970s.

1. Meet C

C is a compiled language and a foundation of systems programming. You need a C compiler to run it. The program starts in main and uses printf to display text.

#include <stdio.h>

int main(void) {
    printf("Hello, C!\n");
    return 0;
}

Practice: Save the program as hello.c and compile it with gcc hello.c -o hello.

2. Data and operators

Every variable in C has a type. int holds whole numbers and float holds decimal numbers. Arithmetic operators let you calculate with values.

#include <stdio.h>
int main(void) {
    int a = 4, b = 3;
    printf("Sum: %d\n", a + b);
    return 0;
}

Practice: Print the sum and product of two numbers.

3. Conditions and loops

if checks a condition and a for loop repeats work. Statements generally end with a semicolon.

#include <stdio.h>
int main(void) {
    for (int i = 1; i <= 5; i++) {
        if (i % 2 == 0) printf("%d\n", i);
    }
    return 0;
}

Practice: Change the code to show odd numbers from 1 to 10.

4. Functions

A function groups instructions behind a name. Its parameter types and return type describe the data it accepts and produces. Functions help reduce duplication.

#include <stdio.h>
int double_value(int n) {
    return n * 2;
}
int main(void) {
    printf("%d\n", double_value(4));
    return 0;
}

Practice: Write a function that returns the larger of two integers.

5. Introducing pointers

A pointer stores an address. The & operator gets a variable’s address and * accesses the pointed-to value. Only dereference pointers that refer to valid objects.

#include <stdio.h>
int main(void) {
    int value = 10;
    int *ptr = &value;
    printf("%d\n", *ptr);
    return 0;
}

Practice: Change the value through the pointer and print the original variable.

HTML & CSS Essentials

HTML describes the structure and meaning of a web page; CSS controls its presentation. Together they are the foundation for accessible, responsive websites.

Background: HTML was introduced by Tim Berners-Lee; CSS was developed by Håkon Wium Lie and Bert Bos.

1. Structure with HTML

HTML gives a web page its structure. Elements such as headings, paragraphs and links organize content. Save the code below as index.html and open it in a browser.

<!doctype html>
<html lang="en">
  <body>
    <h1>Hello, web!</h1>
    <p>My first page.</p>
  </body>
</html>

Practice: Change the page to include your name and a favorite topic.

2. Style with CSS

CSS controls colors, fonts and spacing. A selector chooses an element, and declarations set its styles.

<style>
  body { font-family: sans-serif; }
  h1 { color: seagreen; }
  p { padding: 16px; }
</style>

Practice: Change your heading color and paragraph padding.

3. Layout and responsive design

Flexbox helps arrange elements in a row or column. A viewport meta tag and media queries make pages easier to use across devices.

<meta name="viewport" content="width=device-width, initial-scale=1">
<style>
  .row { display: flex; gap: 1rem; }
  @media (max-width: 600px) {
    .row { flex-direction: column; }
  }
</style>

Practice: Create two cards that stack on a small screen.

JavaScript Basics

JavaScript brings behavior to websites and also runs outside the browser. It lets you respond to input, manipulate data and build interactive applications.

Background: Created by Brendan Eich in 1995 for the Netscape browser.

1. Meet JavaScript

JavaScript adds interactivity to web pages. Run this code in your browser developer console. const creates a binding that cannot be reassigned.

const greeting = "Hello, JavaScript!";
console.log(greeting);

Practice: Show a message with your name in the console.

2. Functions and conditions

Functions package reusable behavior. Use if and else to produce different results based on conditions.

function greet(name) {
  if (name) return `Hello, ${name}!`;
  return "Hello, learner!";
}
console.log(greet("Mita"));

Practice: Write a function that returns double a number.

3. Page interactions

The DOM lets JavaScript find and change HTML elements. Use addEventListener to respond to events such as clicks.

<button id="hello">Click me</button>
<script>
  document.querySelector("#hello")
    .addEventListener("click", () => {
      alert("Keep learning!");
    });
</script>

Computer Science Foundations

Computer science studies computation, information and the methods used to solve problems. Strong fundamentals help you reason about correctness and efficiency across languages.

Background: Computer science evolved through the work of many pioneers, including Ada Lovelace, Alan Turing and Grace Hopper.

1. Problem solving and algorithms

An algorithm is a clear sequence of steps for solving a problem. Before starting, write down the input, expected output and small examples. Then test each step.

Problem: Find the larger number
1. Read a and b
2. If a > b, return a
3. Otherwise, return b

Practice: Write the steps for finding the largest of three numbers.

2. Data structures

Data structures organize information. A list or array stores values in order; a map or dictionary looks up values by key. Choose a structure that fits the problem.

numbers = [10, 20, 30]
student = {"name": "Mita", "score": 90}
print(numbers[0])
print(student["name"])

Practice: Create a list of three favorite books.

3. Complexity and testing

Big O describes how work grows as input grows. Visiting every item in a list once is O(n). Test solutions with normal, empty and boundary cases.

def total(numbers):
    result = 0
    for number in numbers:  # one pass: O(n)
        result += number
    return result

print(total([1, 2, 3]))

Practice: Test the function with an empty list and negative numbers.

Go Fundamentals

Go is a compiled language focused on simplicity, fast builds and practical tooling. It is commonly used for network services, cloud infrastructure and command-line tools.

Background: Designed at Google by Robert Griesemer, Rob Pike and Ken Thompson; announced in 2009.

1. Meet Go

Go is a compiled language designed for clear, practical software. Install Go, save the example as main.go and run it with go run main.go.

package main

import "fmt"

func main() {
    fmt.Println("Hello, Go!")
}

Practice: Change the greeting to include your name.

2. Variables and functions

Use := to declare and initialize a local variable. Functions receive values through parameters and may return a result.

func double(n int) int {
    return n * 2
}

// Inside main:
value := double(4)
fmt.Println(value)

Practice: Write a function that adds two integers.

3. Loops and slices

Go uses for for looping. A slice is a flexible view over a sequence of elements. The range form lets you iterate through values.

numbers := []int{1, 2, 3}
for _, number := range numbers {
    fmt.Println(number)
}

Practice: Create a slice of three names and print each one.

SQL & Databases

SQL is a language for working with relational databases. You can define tables, retrieve information and update records while expressing the data you need.

Background: Developed at IBM in the 1970s by Donald Chamberlin and Raymond Boyce.

1. Tables and rows

Relational databases organize data into tables containing rows and columns. A primary key uniquely identifies each row. Try the following in a SQLite environment.

CREATE TABLE courses (
  id INTEGER PRIMARY KEY,
  title TEXT NOT NULL
);
INSERT INTO courses (id, title) VALUES (1, 'Python');

Practice: Add a second course with a unique id.

2. Reading data

SELECT retrieves columns from a table. WHERE filters rows, and ORDER BY sorts results. SQL keywords are case-insensitive; uppercase is a common convention.

SELECT id, title
FROM courses
WHERE id > 0
ORDER BY title;

Practice: Select only the title of the course with id 1.

3. Updating safely

UPDATE changes existing rows and DELETE removes them. Always check the WHERE clause: without one, these statements affect every row. Back up important data first.

UPDATE courses SET title = 'Python Basics' WHERE id = 1;
SELECT * FROM courses WHERE id = 1;

Practice: Update the title of your second course and confirm the result.

Git & Collaboration

Git is a distributed version-control system that records changes over time. It helps individuals and teams experiment, review work and collaborate safely.

Background: Created by Linus Torvalds in 2005 to support Linux kernel development.

1. Your first repository

Git records versions of files in a repository. Install Git, create a new folder, and run git init to begin. git status shows the current state of your working tree.

mkdir my-project
cd my-project
git init
git status

Practice: Create a file named notes.txt in your new repository.

2. Making a commit

A commit is a snapshot of staged changes. Review your changes, stage the files you want, then commit with a clear message. Configure your Git name and email if prompted.

git status
git add notes.txt
git commit -m "Add learning notes"
git log --oneline

Practice: Update your notes and make another descriptive commit.

3. Branches and collaboration

A branch gives work its own line of development. Create a branch, make changes, and merge it after review. On shared projects, pull requests let others review before merging.

git switch -c add-notes
# edit and commit your changes
git switch main
git merge add-notes

Practice: Create a practice branch and commit a small change. Check your default branch name before switching back.

AI Foundations

AI covers approaches to building systems that perform tasks associated with human intelligence. Machine learning uses data to learn patterns, but results still require evaluation and human judgment.

Background: AI has many contributors; John McCarthy coined the term “artificial intelligence” in 1956.

1. What is machine learning?

Machine learning builds models that learn patterns from data. Supervised learning uses labeled examples, while unsupervised learning looks for structure without labels. A prediction is not a guarantee.

Example task: classify an email as spam or not spam
Input: email text
Label: spam or not spam
Output: predicted label

Practice: Describe one real-world prediction problem and identify its input and output.

2. Training and evaluation

Split data into training and evaluation sets. The model learns from training examples; evaluation on unseen data estimates how well it may generalize. Avoid leaking evaluation data into training.

data = ["example 1", "example 2", "example 3", "example 4"]
train = data[:3]
test = data[3:]
print("train:", train, "test:", test)

Practice: Explain why evaluating on the same examples used for training can be misleading.

3. Responsible AI

AI systems can produce incorrect, biased or sensitive outputs. Check results against reliable sources, protect private information, and assess impacts on the people affected. Human judgment remains important.

Before using an AI output:
1. Verify important claims.
2. Check for bias and missing context.
3. Protect private data.
4. Keep a human accountable.

Practice: Write a short checklist for safely using AI in a study project.
