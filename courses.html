Python Basics

Python is a general-purpose language used for automation, web applications, data analysis and machine learning. Its readable syntax makes it a welcoming first language, while its ecosystem supports serious production work.

Background: Created by Guido van Rossum; first released in 1991.

1. Meet Python

Python is a readable, widely used programming language. Use print() to display text. To practice, install Python and run it in a terminal, or use a trusted online Python environment.

print("Hello, world!")
print("I am learning Python")

Practice: Print a greeting using your own name.

Understanding this concept

A program is a sequence of instructions. Python reads each print call and writes its argument to the output. A quoted message is a string: the quotation marks mark where the text begins and ends, but are not printed.

Predict the two output lines before running the code. Experiment by editing one message at a time; if Python reports a syntax error, check matching quotation marks and parentheses first.

Learn step by step

  1. Read the two print calls and predict the two lines of output.
  2. Run the example in the practice studio and compare its output with your prediction.
  3. Replace the second message with a greeting containing your name, then run it again.

Tip: Keep the quotation marks paired. Text inside the quotes is a string, not a command.

2. Variables and data

Variables store information. A string contains text, while an integer is a whole number. Python infers the type from the value. Use an f-string to insert variables into text.

name = "Mita"
age = 18
print(f"Hello {name}, age {age}")

Practice: Store your favorite subject in a variable and print it.

Understanding this concept

A variable is a name bound to a value. The name and age values have different types: the quoted name is text, while 18 is an integer. An f-string substitutes expressions inside braces into a new string.

Reassigning a name changes the value it refers to. Try a different name and age, then inspect the output. Variable names should describe their purpose, and Python treats uppercase and lowercase names as different.

Learn step by step

  1. Identify the string assigned to name and the integer assigned to age.
  2. Predict the output of the f-string before running it.
  3. Change both values and run the program again.

Tip: Use quotes for text. In an f-string, put the variable name inside braces and place f before the opening quote.

3. Conditions and loops

Use if to run code conditionally and a for loop to repeat an action. Indentation—the whitespace at the start of a line—is important in Python.

for number in range(1, 4):
    if number > 1:
        print(number)

Practice: Print the numbers from 1 to 5 and identify the even numbers.

Understanding this concept

range(1, 4) produces 1, 2 and 3; the upper bound is excluded. The for loop visits each number, and the if block runs only when number is greater than 1.

Python uses indentation to define blocks. Trace the loop on paper and check the output, then change the range or comparison. Consistent indentation matters: spaces at the wrong level can change behavior or cause an error.

Learn step by step

  1. List the values produced by range(1, 4): 1, 2 and 3.
  2. For each value, decide whether number > 1 is true.
  3. Run the program and explain why it prints 2 and 3, not 1.

Tip: The end value in range(1, 4) is excluded. Keep the indented lines aligned within their blocks.

4. Functions and return values

Functions group reusable behavior. Parameters receive input, and return sends a result back to the caller. Give functions names that describe what they do and test them with different inputs.

def square(number):
    return number * number

print(square(5))

Practice: Write a function that converts minutes to seconds. Test it with zero and a positive value.

Understanding this concept

A function definition names a reusable operation. When square(5) is called, the argument 5 is bound to the parameter number; the return statement passes the product back to the caller.

The outer print displays the returned value. Distinguish returning from printing: a returned value can also be stored or used in another calculation. Test zero and negative inputs as well as positive ones.

Learn step by step

  1. Find the parameter number in the function definition.
  2. Trace square(5): substitute 5 for number and calculate 5 * 5.
  3. Change the argument, rerun the example and compare the returned value.

Tip: return sends a value back; print displays a value. A function can return a result without printing it.

5. Handling errors

Programs can fail when input is invalid. Use try and except to handle expected exceptions without hiding unrelated problems. ValueError occurs when text cannot be converted to an integer.

try:
    number = int("42")
    print(number * 2)
except ValueError:
    print("Please enter a whole number")

Practice: Change the input to non-numeric text and observe the result.

Understanding this concept

int converts valid integer text to an integer. If conversion fails, Python raises ValueError and the matching except block displays a friendly message; other exception types are not caught by this handler.

The example converts a fixed string, not keyboard input. Change it to nonnumeric text to exercise the error path. Catch the specific exception you expect and avoid hiding unrelated errors during debugging.

Learn step by step

  1. Run the example with "42" and observe the result 84.
  2. Change "42" to "hello" and rerun it.
  3. Compare the two outputs and identify which block handled the invalid input.

Tip: Catch errors you expect. Avoid hiding unrelated errors, which can make bugs harder to find.

6. Lists and iteration

Lists collect values in order and can be changed. Iteration lets a program process each item without writing a separate print statement.

Understanding this concept

Create a list with square brackets and commas. Index 0 refers to the first item; accessing an index beyond the list raises IndexError. append adds an item to the end of the existing list.

A for loop visits each element in order. Before running the example, predict the number of output lines; then add and remove an item and compare. Avoid modifying a list while iterating over it until you understand the consequences.

topics = ["Python", "SQL", "Web"]
topics.append("Git")
for topic in topics:
    print(topic)

7. Dictionaries and safe lookups

Dictionaries associate keys with values. They are useful when each piece of information has a descriptive name.

Understanding this concept

A dictionary literal uses braces and key-value pairs. In the example, the keys "name" and "score" identify two values. Use square brackets to access a key you know exists.

A missing key accessed with square brackets raises KeyError. The get method can supply a fallback for a missing key, which is useful when data is optional. Validate real user input rather than silently assuming every value is present.

learner = {"name": "Mita", "score": 85}
print(learner["name"])
print(learner.get("course", "Not selected"))

Getting Started with Rust

Rust is a systems language designed to combine performance with strong memory-safety guarantees. Its ownership model helps catch many errors before a program runs.

Background: Started by Graydon Hoare at Mozilla; the first stable release arrived in 2015.

1. Meet Rust

Rust is a systems programming language that emphasizes performance and memory safety. After installing Rust, create a project with cargo new hello and run it with cargo run.

fn main() {
    println!("Hello, Rust!");
}

Practice: Change the program to display a message with your name.

Understanding this concept

Rust programs are compiled before they run. A complete executable defines fn main; println! is a macro that writes a line. Cargo manages projects and invokes the toolchain.

This course editor is a scratchpad, not a Rust compiler. Copy the example into a local Cargo project or the linked Rust environment, then change and rerun the message. Read compiler errors carefully.

2. Variables and mutability

In Rust, let creates a variable. Variables are immutable by default; use mut when a value needs to change. Rust can often infer the type.

fn main() {
    let mut score = 1;
    score += 1;
    println!("Score: {}", score);
}

Practice: Create a mutable counter and increase its value.

Understanding this concept

let introduces a binding. Rust bindings are immutable by default; mut permits reassignment. The example increments score and formats the value with the {} placeholder.

Immutability makes accidental changes easier to notice. Remove mut and observe the compiler diagnostic in a Rust toolchain, then restore it. Mutability of a binding is distinct from ownership and borrowing.

3. Understanding ownership

Each value in Rust has an owner. When its owner leaves scope, the value is cleaned up. Borrowing lets you use a reference without taking ownership, helping keep memory safe.

fn main() {
    let name = String::from("Sayanox");
    let borrowed = &name;
    println!("{}", borrowed);
    println!("{}", name);
}

Practice: Create a String and print it through a reference.

Understanding this concept

An owned String has one owner. The example borrows it through &name and prints through that reference without taking ownership, then prints the original name.

References must not outlive the value they borrow. The compiler checks borrowing rules to prevent invalid access; practice by tracing when the reference is used and when the owner goes out of scope.

4. Functions and control flow

Functions use fn and may return a typed value. An if expression can select a value; both branches must have compatible types.

fn double(value: i32) -> i32 {
    value * 2
}

fn main() {
    println!("{}", double(4));
}

Practice: Write a function that returns the larger of two integers.

Understanding this concept

A function states the type of each parameter and its return type. In this example the final expression value * 2 has no semicolon, so it is returned as an i32.

The main function calls double(4) and displays 8. Try another input in a Rust toolchain. A semicolon after the final expression changes it into a statement, which changes what the function returns.

5. Recoverable errors

Rust represents recoverable errors with Result<T, E>. Match forces you to consider success and failure explicitly, rather than silently ignoring an error.

fn main() {
    let parsed = "42".parse::<i32>();
    match parsed {
        Ok(n) => println!("{}", n),
        Err(e) => println!("Invalid number: {}", e),
    }
}

Practice: Try parsing a word instead of a number and inspect the error.

Understanding this concept

Parsing may succeed or fail, so parse returns a Result. match handles Ok(n) and Err(e) separately, making the successful and error paths explicit.

The string "42" parses successfully as an i32. Replace it with a word and run it in a Rust environment to see the error path. Handle the failure rather than assuming input is always valid.

6. Collections with vectors

A vector stores a sequence of values of the same type and can grow when it is mutable.

Understanding this concept

vec! creates a vector. push appends an item, and a for loop can visit borrowed elements with &topics without taking ownership of the vector.

After iterating over references, the vector remains available for later use. Run the complete program in a Rust compiler, then try an empty vector and discuss how its element type is determined.

fn main() {
    let mut topics = vec!["Rust", "Git"];
    topics.push("SQL");
    for topic in &topics {
        println!("{}", topic);
    }
    println!("Total: {}", topics.len());
}

7. Optional values with Option

Option represents a value that may be present or absent without using a null reference.

Understanding this concept

Some(value) represents a present value and None represents its absence. match requires the program to consider both alternatives, which makes the fallback explicit.

The type annotation Option<i32> says that a present value would be an integer. Switch the example between Some(7) and None in a Rust toolchain and trace which branch runs.

fn main() {
    let score: Option<i32> = Some(7);
    match score {
        Some(value) => println!("Score: {}", value),
        None => println!("No score yet"),
    }
}

C Programming

C is a foundational compiled language used in operating systems, embedded devices and performance-sensitive software. It offers a close view of how programs use memory.

Background: Developed by Dennis Ritchie at Bell Labs in the early 1970s.

1. Meet C

C is a compiled language and a foundation of systems programming. You need a C compiler to run it. The program starts in main and uses printf to display text.

#include <stdio.h>

int main(void) {
    printf("Hello, C!\n");
    return 0;
}

Practice: Save the program as hello.c and compile it with gcc hello.c -o hello.

Understanding this concept

C source code is compiled into a program. main is the entry point and printf writes formatted output; the include directive provides the declaration for printf.

The editor here does not compile C. Save the example and use a local compiler or the linked external tool. Compile with warnings enabled and read diagnostics before running your program.

2. Data and operators

Every variable in C has a type. int holds whole numbers and float holds decimal numbers. Arithmetic operators let you calculate with values.

#include <stdio.h>
int main(void) {
    int a = 4, b = 3;
    printf("Sum: %d\n", a + b);
    return 0;
}

Practice: Print the sum and product of two numbers.

Understanding this concept

A variable declaration gives each value a type. int holds integer values within its implementation-defined range; operators such as + and * combine values. printf uses %d for an int.

Change a and b, then predict the sum and product. C does not automatically check every mistake: use appropriate format specifiers, and do not assume integer overflow is harmless.

3. Conditions and loops

if checks a condition and a for loop repeats work. Statements generally end with a semicolon.

#include <stdio.h>
int main(void) {
    for (int i = 1; i <= 5; i++) {
        if (i % 2 == 0) printf("%d\n", i);
    }
    return 0;
}

Practice: Change the code to show odd numbers from 1 to 10.

Understanding this concept

A for loop initializes a counter, checks a condition and changes the counter on each iteration. The remainder expression i % 2 is zero for an even integer.

Trace i from 1 through 5: only 2 and 4 are printed. Change the condition carefully to show odd numbers, and confirm the loop has a reachable stopping condition.

4. Functions

A function groups instructions behind a name. Its parameter types and return type describe the data it accepts and produces. Functions help reduce duplication.

#include <stdio.h>
int double_value(int n) {
    return n * 2;
}
int main(void) {
    printf("%d\n", double_value(4));
    return 0;
}

Practice: Write a function that returns the larger of two integers.

Understanding this concept

A function has a return type, name and typed parameters. double_value receives an int and returns twice that value; main passes 4 and prints the result.

Extracting a named operation makes it reusable and testable. Try inputs 0 and a negative value. For real programs, consider the range of the type and avoid signed overflow.

5. Introducing pointers

A pointer stores an address. The & operator gets a variable’s address and * accesses the pointed-to value. Only dereference pointers that refer to valid objects.

#include <stdio.h>
int main(void) {
    int value = 10;
    int *ptr = &value;
    printf("%d\n", *ptr);
    return 0;
}

Practice: Change the value through the pointer and print the original variable.

Understanding this concept

A pointer stores an address. &value obtains the address of value, while *ptr reads the int at that address. The pointer is valid here because value remains alive while it is used.

Never dereference a null, uninitialized or dangling pointer. Try assigning through *ptr, then print value to see the same object change. Use a compiler and debugging tools when exploring memory errors.

6. Arrays and bounds

An array stores a fixed number of elements of the same type. Indexing starts at zero.

Understanding this concept

In this example scores has three int elements at indices 0, 1 and 2. A loop visits the valid indices and prints each value.

C does not automatically check every array access. Reading or writing outside the array is undefined behavior, so keep loop bounds consistent with the array length and use compiler warnings and runtime tools.

#include <stdio.h>
int main(void) {
    int scores[] = {7, 8, 9};
    size_t count = sizeof scores / sizeof scores[0];
    for (size_t i = 0; i < count; i++) {
        printf("%d\n", scores[i]);
    }
    return 0;
}

Learn step by step

Learning goal: Iterate over every valid array index without going past the end.

7. Strings as character arrays

In C, a string is a sequence of char values terminated by a zero byte, written as \0.

Understanding this concept

The compiler includes a terminating zero when initializing the array from a string literal. printf with %s reads characters until that terminator.

The destination array must have enough space for both the text and its terminator. Avoid unsafe copying and never use untrusted text as a format string. Compile with warnings and test in a safe practice environment.

#include <stdio.h>
int main(void) {
    char name[] = "Mita";
    printf("Hello, %s!\n", name);
    return 0;
}

1. What is machine learning?

4. Classification metrics

Accuracy measures the proportion of predictions that are correct, but it can hide important mistakes when classes are imbalanced.

print("recall:", recall)
