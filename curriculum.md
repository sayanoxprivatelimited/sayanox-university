# Curriculum Roadmap — Sayanox University

This is the recommended learning path. Follow the order unless you already have strong foundations in a track.

---

## Phase 0 — Foundations (Start Here)

**Goal:** Become a deliberate learner and set up a high-leverage environment.

- How to learn technical subjects effectively
- Mental models & first principles thinking
- Problem solving frameworks
- Tooling: terminal, git, editor, note-taking system
- Building a personal knowledge system

→ [`tracks/00-foundations`](tracks/00-foundations)

---

## Phase 1 — Programming Mastery

**Goal:** Write clean, correct, and efficient code with confidence.

### Core
- Python deeply (beyond tutorials)
- Data structures in practice
- Error handling, testing, debugging
- Writing readable & maintainable code

### Systems Language (pick one)
- C (for understanding memory & machines)
- Go (for practical systems work)
- Rust (for safety + performance)

→ `tracks/01-programming`

---

## Phase 2 — Computer Science Core

**Goal:** Build the theoretical backbone every strong engineer needs.

- Algorithms & Complexity
- Advanced Data Structures
- Discrete Mathematics essentials
- Graph theory & applications
- Basic computability & complexity classes

→ `tracks/02-computer-science`

---

## Phase 3 — Software Engineering

**Goal:** Learn how real software is designed, built, and maintained.

- Software design principles (SOLID, composition, etc.)
- Testing strategies (unit, integration, property-based)
- Architecture patterns
- Code review & collaboration
- Technical debt & refactoring
- Documentation as a first-class citizen

→ `tracks/03-software-engineering`

---

## Phase 4 — Systems

**Goal:** Understand how computers and networks actually work.

- Operating Systems fundamentals
- Computer Networking (TCP/IP, HTTP, etc.)
- Concurrency & Parallelism
- Databases (storage, indexing, transactions)
- Distributed Systems basics

→ `tracks/04-systems`

---

## Phase 5 — Artificial Intelligence

**Goal:** Go from foundations to building useful AI systems.

- Machine Learning fundamentals
- Deep Learning core concepts
- Large Language Models (architecture, training, inference)
- Applied AI Engineering (RAG, agents, evaluation, production)
- Safety, evaluation & limitations

→ `tracks/05-artificial-intelligence`

---

## Phase 6 — Projects & Capstones

**Goal:** Prove mastery by shipping real systems.

You will build multiple projects of increasing complexity, ending with one major capstone that demonstrates depth across multiple tracks.

→ `tracks/06-projects`

---

## Suggested Pace

| Intensity | Hours / week | Expected progress |
|-----------|--------------|-------------------|
| Light     | 6–8          | 1 track / 2–3 months |
| Serious   | 12–15        | 1 track / 4–6 weeks |
| Intense   | 20+          | Faster, but watch burnout |

Consistency beats intensity.

---

## Rules of Engagement

1. Do not skip exercises.
2. Write your own notes.
3. Build something after every major topic.
4. Review previous material regularly.
5. Prefer depth over speed.
