A SUGGESTED PATH

Your learning roadmap

Start with foundations, practice each subject, and move at your own pace. These courses are introductory; this is a suggested order, not a professional qualification.

  1. Computer Science Foundations

    Learn problem solving, data structures and basic complexity.

    Open classroom ↗ · Read without JavaScript

  2. Python Basics

    Practice variables, functions, loops and error handling.

    Open classroom ↗ · Read without JavaScript

  3. HTML & CSS, then JavaScript

    Build and add behavior to responsive web pages.

    HTML & CSS ↗ · JavaScript ↗

  4. Git & SQL

    Track your work and learn to query structured data.

    Git ↗ · SQL ↗

  5. Explore systems languages

    Pick a language and explore its tools and trade-offs.

    C ↗ · Rust ↗ · Go ↗

  6. AI Foundations

    Learn how to frame, evaluate and responsibly use machine learning.

    AI Foundations ↗

Want to practice? Each course includes a self-guided project and an optional knowledge check.
