# 04 · Environment & Tools

**Why this matters:**  
Your daily tools multiply (or destroy) your productivity. A sharp environment compounds over years.

---

## Learning Outcomes

- Use the terminal confidently
- Master Git for real workflows (not just `add/commit/push`)
- Configure a powerful editor setup
- Build a consistent personal development environment

---

## Core Areas

### Terminal
- Navigation, searching, pipelines, process management
- Shell configuration (aliases, functions, prompt)
- Comfort with `tmux` or equivalent

### Git
- Branching strategies
- Interactive rebase, bisect, reflog
- Writing good commit messages
- Understanding the object model at a basic level

### Editor
- Choose one (Neovim, VS Code, Zed, etc.) and go deep
- Keybindings, snippets, project-wide search, debugging integration

### Workflow
- Dotfiles management
- Consistent project structure
- Fast feedback loops (tests, formatters, linters)

---

## Exercises

1. Spend one focused session improving your shell configuration. Document the changes.
2. Practice interactive rebase on a practice repository until it feels natural.
3. Create a minimal but powerful editor setup for Python (or your main language) and write down why each plugin/setting exists.
