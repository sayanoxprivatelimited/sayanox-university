# 00 · Foundations

**Status:** In progress  
**Goal:** Become a deliberate learner and build a high-leverage personal system.

This track is the foundation of everything else in Sayanox University.  
Skip it at your own risk.

---

## Learning Outcomes

By the end of this track you will be able to:

- Learn technical subjects faster and more deeply
- Think in mental models and first principles
- Break down hard problems systematically
- Maintain a personal knowledge system
- Use your tools (terminal, git, editor) fluidly
